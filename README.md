# 🚀 MindX AI Internship - AI Projects Portfolio

## 📌 Overview
This repository showcases the work completed during my internship at **MindX AI Company**, where I built intelligent AI-powered applications using **Microsoft Azure AI Services**. The internship focused on designing scalable, real-world solutions in conversational AI, automation, and voice-based systems.

---

## 🧠 Projects Included

### 1️⃣ CreawAI - Intelligent Content & Workflow Assistant
**Description:**  
CreawAI is an AI-powered assistant that automates content generation and enhances productivity through smart workflows.

**Key Features:**
- AI-driven content generation (blogs, summaries, structured outputs)
- Prompt engineering for optimized responses
- Integration with Azure OpenAI services
- Modular and scalable architecture
- Context-aware intelligent responses

**Technologies Used:**
- Python  
- Azure OpenAI Service  
- REST APIs  
- Prompt Engineering  

---

### 2️⃣ FAQ Chatbot – Automated Query Resolution System
**Description:**  
A smart chatbot designed to answer frequently asked questions using natural language understanding and a structured knowledge base.

**Key Features:**
- Context-aware FAQ retrieval  
- Semantic search using embeddings  
- Real-time response generation  
- Scalable backend architecture  
- Custom knowledge base integration  

**Technologies Used:**
- Python  
- Azure Cognitive Services  
- Azure OpenAI  
- Vector embeddings / semantic search  
- Flask / FastAPI  

---

### 3️⃣ Voice Chatbot – Conversational AI with Speech Capabilities
**Description:**  
A voice-enabled chatbot that allows users to interact naturally through speech for a seamless conversational experience.

**Key Features:**
- Speech-to-Text (STT) and Text-to-Speech (TTS)  
- Real-time voice interaction  
- Multi-turn conversation handling  
- Low-latency processing  
- Integration with AI models for intelligent responses  

**Technologies Used:**
- Python  
- Azure Speech Services  
- Azure OpenAI  
- Audio processing libraries
